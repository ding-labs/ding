# Ding 0.15.2

macOS notification banners and System Settings now use Ding's green bell instead
of the generic application icon. All product surfaces use the official artwork:
the full green circle sits in front of the gray mounting base. The website, docs,
Console, MCP interface, plugin icons, and social artwork share this corrected mark.

The helper includes native icon sizes generated
from the same artwork as Ding Console, and registers its current bundle metadata
when the CLI starts it. Its bundle version now follows the Ding release.

```sh
ding service stop
brew update
brew upgrade ding-labs/tap/ding
ding setup
ding notify test
```

Send a new test after upgrading. Reopen System Settings if it was open during the
upgrade. Notification permissions and existing watch data are retained.
