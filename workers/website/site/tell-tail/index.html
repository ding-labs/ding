Install with Cargo

Requires Rust 1.88 or later.

cargo install tell-tail --version {{tellTailVersion}} --locked

Codex desktop plugin

On an Apple Silicon Mac, open Tell-Tail in Codex and choose Install.

Use in Codex

First visit? The button opens Plugins. Choose Add → Add a marketplace, enter zuchka/tell-tail-plugins, and select Add marketplace. Then click Use in Codex again to open the listing.

Open a new local Codex chat and ask “Open my Codex logs.” The dashboard follows supported desktop logs immediately.

For ongoing tool-call tracing, ask “Set up persistent tool-call tracing,” approve setup, and restart Codex once.
